## 这轮解决的问题

1. v2 默认页面让空预览占据主要空间，拟输出与目标位于下方。v3 默认先显示拟输出文件、对象去向、容器与保存位置设计，再显示编码目标；画面预览按需进入。
2. 增加容器与保存位置的可见设计。保存位置明确为待接入，不假定已经取得文件系统权限或已经创建输出。
3. 单独绘制桌面 D06 与平板 T04 预览状态。示例源画幅为 16:9，视口精确为 772×434.25 与 596×335.25；没有载入真实帧，保持明确空状态。实现必须根据来源显示宽高比（含 SAR）计算，不是将所有视频强制 16:9。
4. 主动作明确为“检查并开始压制/转码/剪切”；候选比较页说明当前正式计划仍为原方案，推荐没有自动采用。
5. 候选比较页检查器改为决策目标、场景采样、候选空间与参考域，当前选中决策类别。
6. 修正静态成品页的状态矛盾：逐流保留差分等必需检查未完成时，两个保存入口使用 Disabled 组件；常驻说明原因，提供运行必需检查与导出检查报告。可选播放器复开不被混同为所有情况下的强制门槛。
