# 中央软字幕与附件逐对象保留 · 2026-10-16

## 范围与授权

用户继续补基础功能；本单元重新读取 R19 §03/07、R24 §04/05 与初版追踪矩阵，锚点 B02/B04/B05/B20。中央输出面板已有类型保留开关，但具体字幕/附件子集仍藏在完整正式参数。此次只接通现有逐对象复制/排除能力，高级色彩、通用提取、预选目录不进入本单元。

## 实现

中央“音轨、字幕与附件去向”按探测事实列出软字幕与附件/字体，可逐个保留或排除。各类序号明确使用 FFmpeg s:N / t:N 的来源顺序，不混用全局 stream.index。显示语言、标题/文件名等实际标签。

代理没有命名字段或第二份任务状态。更改经原 keepSubtitles/subtitleStreams、keepAttachments/attachmentStreams 正式控件处理器，原编译器形成输出计划与 FFmpeg map；取消最后一项会关闭该类型保留，重新勾选形成显式子集。原有类型开关和完整编辑器更改会同步投影。

执行锁、引导模式、来源对象及 name/size/lastModified、清单签名/计数保护写入。正式选择无法映射来源时不擅自重写，清单不完整时不允许逐对象选择。超过 32 个对象的来源使用完整正式参数，现有策略保留。手机仍保留原布局。

软字幕保留不等于硬字幕烧录，不自动选择内封 ASS 作为烧录源，也不等于提取文件。字幕与字体依赖关系仍需用户与实际检查确认，不推断附件已经满足渲染需求。
