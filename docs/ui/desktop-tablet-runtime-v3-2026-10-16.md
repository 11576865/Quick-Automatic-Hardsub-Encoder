# QHE Figma v3 实际界面落实

用户授权：按设计图布置实际 UI，功能入口可以先预留、后续接入。范围是桌面和平板；来源 R24 §19–20 / B20，关联 B02/B05，未改变初始版本的验收分母。

设计依据：[Figma v3](https://www.figma.com/design/FPHdsXxN7xNniLKjZQcVKd?node-id=3-2)。应用从 768px 启用新工作台；横屏三栏，竖屏保留左侧来源并将检查器放到计划下方。手机恢复原控件与阶段控制，不新增手机设计。

## 已布置的界面

- 应用栏、三类工作流、真实来源/计划/成品状态路径，标准/紧凑/自动动作标签。
- 来源与依赖、真实流与附件名称；字幕和字体选择收在可展开区域，原节点与事件保留。
- 拟输出文件、容器入口、保存位置占位、目标与编码决策；完整正式参数通过披露入口继续访问。
- 按需展开画面预览；来源显示比例包含已探测 SAR，未知来源保持明确空状态。硬字幕与转码/复制使用各自实际帧。
- 候选比较中央视图与现有真实测量面板入口，不生成示例曲线、不自动采用推荐。
- 成品审计中央视图、真实事实/证据、报告与保存入口。保存按钮及页脚严格镜像实际保存门槛，点击时再次检查真实按钮状态。
- 输出意图检查器保留独立草稿身份，不写入执行表单；帮助弹窗可用 Escape 关闭。

## 接入边界

| 入口 | 当前行为 |
| --- | --- |
| 选源、ASS/字体、正式参数、检查、编码、时间轴、成品保存 | 复用原有流程及门槛 |
| 输出容器、编码参数、比较、队列与运行设置 | 打开相应实际编辑/诊断区域 |
| 保存位置、通用对象提取 | 明确显示待接入说明 |
| 输出意图、色彩/保留等预期能力 | 可编辑会话草稿，尚未应用执行 |
| 候选曲线及采用操作 | 在现有实际测量面板中操作；新的中央视图提供入口 |

源对象投影使用 adapter 的 `attachmentStreams` 并保留 ffprobe tags 名称；浏览器和 Native JS 适配器保留 SAR，Windows/Android 探测响应各增加一个可选 SAR 属性。没有改变编码参数或新增保存限制。
