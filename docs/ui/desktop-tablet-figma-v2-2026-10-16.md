## 设计依据与边界

承接 R24 §19–20 / B02、B05、B20 与用户本轮提供的两张参考图。参考图的核心是对象、动作、状态、解释四类图标语言，以及按区域提供标准、紧凑、自动标签密度。继续只绘制桌面和平板；保留三条正式工作流、来源与拟输出及实际成品的区分、显式采用候选、Stream Copy 切点限制。

v1 的代码曾通过 PR #113/#114 合入 main@298653f；v2 是 Figma 更新，不能把新工具栏、标签密度或帮助面板称作已接入应用。

## 本轮改进

- 8 个已有应用界面原位更新，原节点链接保留；增加 1 张交互状态与图标语义图 UX01。
- 压缩顶部重复标题、三块阶段卡和永久说明。主工作区 y 坐标由 v1 的 332（桌面/横屏平板）与 324（竖屏）变为 176 与 168，提前 156 个设计像素。画面预览增加明确的视口和播放/设置工具栏；仍使用诚实的空画面示例，未伪造真实素材。
- 视频、音频、字幕、附件、章节、标签使用一致的对象图标；检查、提取、验证、更多属于动作。图标从 Simple Design System 导入复用，不是整页图片。
- 工具栏组件提供 Standard/Compact × Default/Focus/Disabled 六种变体，以及 Label 文本和 Icon 实例交换属性。紧凑变体隐藏视觉标签时保留动作名称；44×44 设计热区。实施时仍须真实 aria-label、键盘行为与触控提示。
- 5 类状态用形状、文字与颜色共同区分。待接入/未测量不再处处使用警告色；Info 是解释入口。主动作、文件名、轨道名、当前值与阻断原因保留文字。
- 平板素材栏保留检查/提取/更多，验证依赖收入更多菜单的设计约定；轨道属性在窄列分两行，保留完整字体文件名。
- UX01 绘制标准、紧凑、自动模式的具体呈现、聚焦动作名称提示、字体替代警告和缺少必需字体的阻断详情。点击/悬停/触控规则为交互规格，不是可运行原型。
