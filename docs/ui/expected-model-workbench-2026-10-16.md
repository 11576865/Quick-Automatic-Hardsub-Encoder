- 默认正式页面加载新的工作台外观与对象导航，沿用现有三种任务入口和真实输入、预览、执行控制。

- 原生下拉框、键盘可操作页签、焦点指示及减少动态效果偏好；实际执行计划入口跳转现有控制。
