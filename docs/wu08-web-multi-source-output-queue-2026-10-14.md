# QHE WU-08 · Web 多来源独立执行任务队列

日期：2026-10-14；理论依据 R19 §16/P5 与 R24 §22，追踪 B21/B02/B24。

## 用户可做什么

在现有 Manual 工作台展开“多来源输出队列”，用户一次选择多个视频文件；最多同时 8 项。加入时每个 File 与其当前 Copy / 纯转码参数被分别保存为不可变意图快照。运行前始终激活该来源的真实 File 对象并探测源时长、流信息，再通过原 `compileTask` v4、validate、run、outputReport、save 链路输出独立文件。

不跨来源复用质量、严格体积、ASS/字体资源、逐轨音频计划和 must-copy 保留锁；当前版本在这些配置出现时明确拒绝排队，不能偷偷丢弃用户设置。用户可停止后续项，某来源编码失败停止后续、此前输出不回滚；保存失败保留成品，单独重试。

Web 保存回执只能证明触发浏览器下载，**不能证明最终文件已真正写入磁盘**。用户须允许多个下载并检查文件。已完成记录可删除或整个队列清空，均不会回溯删除已交给浏览器的输出。

## 不成立的推断

本验收并未实际使用 WebAssembly FFmpeg 编码两部真实媒体，也未验证浏览器下载落盘和播放器播放。Windows/Android 的 Native 多文件权限与切换，跨来源 ASS 和字体，以及完整的多来源×多配方矩阵仍未实现。B21 是**新的局部功能已通过**，不是完整完成。
