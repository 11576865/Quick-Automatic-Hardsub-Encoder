# WU-04 — Stream Copy 切点真实性与用户可选择的重编码路径

理论锚点：R19 §06 (PDF p6–7), R24 §09；B08/B09、A04。状态：提交实现，托管 CI 待确认。

## 新产品行为

- 快速复制模式在请求 IN/OUT 有效时显示独立剪切策略提示。未有当前来源的关键帧证据时明确标记未知；有关键帧时仅展示估计提前的量，不称作成品真实首帧。
- 时间轴关键帧证据绑定 sourceIdentity + videoOrdinal；采集期间换源或选流，丢弃响应，绝不继承上个文件的切点判断。
- 用户可以明确点击并二次确认改为**重编码剪切**；保留 IN/OUT、使用用户当前编码设置，下一次执行仍通过原 `compileTask`，不能自行从 Copy 改 codec。转换后需重新核对编码参数。
- 未实现 Smart Cut；重编码也不代表帧精确签收。尤其 VFR、B 帧、非零音频偏移、负时间戳仍要求独立 output PTS/DTS、首尾包、听看同步检验，不能因 UI 提示通过而关闭整个 A04。

## 边界

这轮交付是对误导性快速复制切点语义的产品纠正，不是每个真实 MKV 的物理 cut 能力证明，也不变更旧快剪编译器或强制用户改用重编码。CI 模型/Chromium 验收绑定精确提交；Windows 用户现场与实际 packet 审计均待完成。
